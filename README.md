# Business Website Builder

Build a multi-page marketing website for [BUSINESS NAME], a [type of business, e.g. plumbing service] in [city].



Pages (separate routes): Home, About, Services, Contact.

Language: [English / Roman Urdu].



Content rules:

- Write all text directly inside the components as plain text. Do NOT fetch content from an API or database.

- No login, no user accounts, no backend, no Supabase.

- Every page must show its full content immediately. Do NOT hide content with scroll-reveal or fade-in animations that start at opacity 0; subtle hover effects are fine.

- Keep animations light and CSS-only.

- Use plain <a> links between pages and one <img> tag per image (images in /public).

- Contact page: a simple form with Name, Phone, Message and a Send button, plus a WhatsApp button linking to https://wa.me/[NUMBER]. No form backend needed.

- Show business phone, address and opening hours in the footer on every page.

- Fully responsive, mobile-first, clean modern design in [colors/style].

- Each text element should be a real semantic tag (h1, h2, p, button). No text inside images.
